Реализовать алгоритм хеш-функции SHA-3 (256). По окончанию выполнения предоставить код, скриншоты теста на малом и большом (>1MB) массиве данных и его сравнение с эталоном. Хеш функции работают непосредственно с файлами.
Язык программирования для выполнения задания на выбор - С, С++, С#, Java. Код должен быть документирован. При написании кода учесть необходимость защиты приложения от уязвимостей реализации. При внедрении кода связанного с информационной безопасностью - оставить пояснительные комментарии и кратко описать проблему. Обязательное условие - программа на вход принимает файлы.
